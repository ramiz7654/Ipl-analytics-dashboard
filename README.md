# IPL Statistics Dashboard

Frontend-only IPL analytics dashboard built with React, Vite, Tailwind CSS and Recharts.

## Setup

1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Data

The `src/data` folder contains processed JSON files generated from the supplied Kaggle IPL ball-by-ball dataset. The original large CSV is intentionally not bundled into the frontend.

## Main features

- Season selector
- Highest individual score
- Most runs
- Most wickets
- Player of the Match leader
- Top batting and bowling charts
- Team wins
- Season snapshot
- Responsive Tailwind UI
